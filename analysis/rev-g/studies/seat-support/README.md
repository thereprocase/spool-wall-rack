# Wider inner-seat support — rejected 3D feedback perturbation

The 5 → 8 mm inner-seat support change reduces coarse front movement to
2.988 mm, but the raw h2 tensile peak is 21.25 MPa. The actual slice is
108.03 g. No refined strength acceptance is claimed.
